# Семейный бюджет (self-hosted)

Учёт регулярных платежей (аренда, коммуналка, страховки, подписки) и ежедневных расходов.
Годовые и квартальные платежи пересчитываются в месячную сумму, есть разбивка по категориям,
остаток от дохода, выгрузка месяца в CSV и импорт банковских CSV-выписок.
Месяц может начинаться с любого числа (например, со дня зарплаты): при старте 25-го
«Ноябрь» — это 25 октября – 24 ноября. Настраивается в плитке «Остаток».

**Стек:** Node.js 22 + Fastify 5 · PostgreSQL 16 · nginx · Docker Compose.

```
браузер ──► nginx (:8080) ──► app: Fastify (:3000) ──► PostgreSQL (только внутренняя сеть)
```

## Запуск

Нужен Docker с Compose v2.

```bash
cp .env.example .env
# в .env поменяйте POSTGRES_PASSWORD, APP_PASSWORD и SESSION_SECRET
openssl rand -hex 32        # результат вставьте в SESSION_SECRET

docker compose up -d --build
```

Откройте http://localhost:8080 и войдите с паролем из `APP_PASSWORD`.
Таблицы создаются автоматически при первом старте (миграции из `app/migrations`).

## Обновление

```bash
git pull   # или замените файлы
docker compose up -d --build
```

Новые миграции применятся сами. Данные хранятся в Docker-томе `pgdata` и не теряются при пересборке.

## Резервная копия

```bash
# сохранить
docker compose exec -T db pg_dump -U budget budget | gzip > backup-$(date +%F).sql.gz

# восстановить в пустую базу
gunzip -c backup-2026-10-23.sql.gz | docker compose exec -T db psql -U budget budget
```

Удобно повесить первую команду на cron раз в сутки.

## Доступ извне

Не открывайте порт 8080 в интернет напрямую. Варианты:

- **Только дома:** оставьте как есть, открывайте по IP сервера в локальной сети.
- **Tailscale:** самый простой способ зайти с телефона откуда угодно, без проброса портов.
- **HTTPS-домен:** поставьте перед nginx Caddy, Traefik или Cloudflare Tunnel и задайте
  `COOKIE_SECURE=true` в `.env`.

## API

Все маршруты, кроме `/api/login`, `/api/me` и `/api/health`, требуют входа (кука сессии).

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/api/login` | `{ "password": "…" }` → кука сессии на 30 дней |
| POST | `/api/logout` | выход |
| GET | `/api/recurring` | все регулярные платежи |
| POST | `/api/recurring` | создать: `name, amount, period (week/month/quarter/year), kind (mandatory/subscription), category, account, day, active` |
| PUT | `/api/recurring/:id` | изменить целиком |
| PATCH | `/api/recurring/:id` | `{ "active": false }` — пауза |
| DELETE | `/api/recurring/:id` | удалить |
| GET | `/api/expenses?month=2026-10` | расходы за календарный месяц; или `?from=2026-10-25&to=2026-11-25` — за период (`to` не входит) |
| GET | `/api/expenses.csv?month=…` / `?from=…&to=…` | то же в CSV (разделитель `;`, открывается в Excel) |
| POST | `/api/expenses` | создать: `amount, date (YYYY-MM-DD), category, note, account, recurring_id` (id регулярного платежа или `null`) |
| PUT | `/api/expenses/:id` | изменить |
| DELETE | `/api/expenses/:id` | удалить |
| GET / PUT | `/api/settings` | `{ "income": 3200, "periodStart": 25 }` — доход в месяц и число, с которого начинается бюджетный месяц |
| POST | `/api/import/preview` | `{ account, rows: [{ date, datetime, amount, original }] }` → строки со статусом `new / imported / skipped` и подсказкой названия и категории из правил |
| POST | `/api/import/commit` | `{ account, items: [{ …строка, n, action: import/skip, note, category }] }` → `{ imported, skipped }` |

## Регулярные платежи и фактические оплаты

Расход можно связать с регулярным платежом (поле «Регулярный платёж» в форме или в строке импорта).
Такой расход не входит в «Расходы за месяц», а закрывает платёж, поэтому ничего не считается дважды.

- **Ежемесячный платёж:** в периоде учитывается фактически оплаченная сумма. Пока оплаты нет,
  учитывается план, а у платежа написано «ещё не списан».
- **Годовой, квартальный, еженедельный:** в итогах остаётся месячная доля по плану, чтобы годовая
  страховка не задвоилась в месяц оплаты. Связанный расход только отмечает платёж как оплаченный.
- **Импорт CSV:** связь подставляется сама, если совпали сумма и слово из названия
  (Netflix 15,99 ↔ «NETFLIX.COM 4421»). Выбор запоминается в правиле вместе с названием и категорией.
- Если удалить регулярный платёж, связанные с ним расходы станут обычными.

## Импорт CSV

Кнопка «Импорт CSV» в шапке. Revolut и Bank of Cyprus определяются по заголовкам. Для другого
CSV нужно выбрать колонки даты, описания и суммы (или списаний). Импортируются только списания:
поступления, операции в обработке и операции не в EUR пропускаются.

- Отмеченные строки становятся расходами, неотмеченные запоминаются как скрытые и больше
  не показываются. Вернуть скрытую можно галочкой «Показать скрытые».
- Транзакция узнаётся по отпечатку исходных данных выписки (счёт, дата/время, сумма, описание),
  поэтому при повторной загрузке не дублируется, даже если её переименовали или удалили расход.
- Если поменять название или категорию, это запомнится как правило для того же описания из банка
  (без цифр: номеров карт и ссылок на платёж) и подставится при следующих импортах.

## Структура

```
docker-compose.yml
.env.example
nginx/default.conf         прокси, gzip, заголовки безопасности (CSP)
app/
  Dockerfile
  package.json
  migrations/001_init.sql  таблицы recurring, expenses, settings
  migrations/002_import.sql  import_tx (виденные транзакции выписок), import_rules (переименования)
  migrations/003_recurring_link.sql  связь расходов и правил импорта с регулярными платежами
  src/server.js            Fastify, запуск миграций
  src/auth.js              вход по паролю, подписанная кука
  src/routes/*.js          REST API с валидацией JSON Schema
  public/                  интерфейс (HTML + CSS + JS без сборки)
  public/csv.js            разбор CSV-выписок (Revolut, BoC, ручной режим)
```

## Разработка без Docker

```bash
cd app
npm install
DATABASE_URL=postgres://user:pass@localhost:5432/budget \
SESSION_SECRET=$(openssl rand -hex 32) APP_PASSWORD=dev npm run dev
# http://localhost:3000
```
